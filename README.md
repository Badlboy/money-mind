# Money Mind — демо-прототип

Клікабельний прототип мобільного застосунку особистих фінансів: тарифи FREE і
Premium, операції, бюджет, цілі, чистий капітал, AI-асистент.

**Це демо.** Нічого не надсилається на сервер — усе, що вноситься, лишається в
браузері пристрою. Імена й суми вигадані; підключення банків, AI й оплата —
імітація.
